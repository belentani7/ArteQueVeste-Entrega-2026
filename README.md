# Arte Que Veste — Paquete integral 2026

Este paquete reúne los materiales generados en la conversación: versiones inicial y final de la presentación, PDFs, fuentes, imágenes, documento original disponible y registro documentado de la conversación.

## Estructura

- `slides_finales/`: presentación HTML final refinada.
- `slides_iniciales/`: versión HTML inicial.
- `manuales/`: PDFs producidos.
- `fuentes/`: Markdown, Typst y proyectos de compilación.
- `imagenes/`: portadas, láminas numeradas y portada mágica.
- `original/`: texto fuente, mapeo y notas de trabajo.
- `CHAT_Y_INVENTARIO.md`: transcripción documentada, inventario y limitaciones.
